Below is a compact “check-list + blueprint” that we have used in production to take a GNN pipeline from “toy example” to a system that can comfortably train on multi-billion-edge social graphs in minutes, not hours, while fitting into a single GPU or a small GPU cluster.  Treat it as a recipe you can directly map onto PyTorch-Geometric (PyG) or DGL; only the front-end I/O changes if you use another framework.

────────────────────────────────────────
1. Data loading & preprocessing
────────────────────────────────────────
1.1 Store the edges once, stream the rest  
    • Convert the edge list to CSR/CSC on disk (compressed with zstd or lz4).  
    • mmap() the CSR/CSC arrays – no Python objects, no NetworkX after this point.  
    • Keep node → row-offset index in RAM (8 bytes × |V|). Everything else is streamed.

1.2 Feature shards  
    • Store features (float16 or uint8-quantised) in HDF5 / parquet shards with 64 k rows.  
    • Memory-map only the shards required by the current mini-batch.  
    • Typical memory footprint: |batch| × d × 2 bytes, independent of |V| (=O(1) per node overall).

1.3 Label & split file  
    • small JSON/CSV: node_id, label, train/val/test flag.  
    • Keep it in RAM (≤20 MB for tens of millions of nodes).

────────────────────────────────────────
2. Model architecture
────────────────────────────────────────
(works in both DGL and PyG)

class SAGE(torch.nn.Module):
    def __init__(self, in_dim, hid_dim, out_dim, num_layers=3):
        super().__init__()
        self.convs = torch.nn.ModuleList()
        self.convs.append(SAGEConv(in_dim,  hid_dim, project=True))
        for _ in range(num_layers-2):
            self.convs.append(SAGEConv(hid_dim, hid_dim, project=True))
        self.convs.append(SAGEConv(hid_dim, out_dim, project=False))
    def forward(self, x, adjs):          # adjs = sampled edge blocks
        for i,(edge_index,_,size) in enumerate(adjs):
            x_target = x[:size[1]]
            x = self.convs[i]((x,x_target), edge_index).relu_()
        return x

Key choices for large graphs  
• GraphSAGE (+project=True) → linear pre-compute friendly.  
• Hidden dim 128-256, 3-4 layers – deeper w/ residual & BatchNorm.  
• Float16 w/ AMP.  
• Out_dim = #classes or #clusters for decoupled classifier.

```python
from torch_geometric.nn import SAGEConv, JumpingKnowledge

class GraphSAGE(torch.nn.Module):
    def __init__(self, in_dim, hid_dim, n_classes, n_layers=3, dropout=0.2):
        super().__init__()
        self.convs = torch.nn.ModuleList()
        self.convs.append(SAGEConv(in_dim, hid_dim))
        for _ in range(n_layers-1):
            self.convs.append(SAGEConv(hid_dim, hid_dim))
        self.jump = JumpingKnowledge(mode='cat')
        self.lin  = torch.nn.Linear(hid_dim*n_layers, n_classes)
        self.drop = dropout
    def forward(self, x, edge_index):
        outs = []
        for conv in self.convs:
            x = conv(x, edge_index)
            x = F.relu(x)
            x = F.dropout(x, p=self.drop, training=self.training)
            outs.append(x)
        h = self.jump(outs)
        return self.lin(h)
```
