### Step-by-Step Plan

1. **Parsing the Function String**: We will use `sympy` to parse the input function string so that we can evaluate the function over a range of values.

2. **Numerical Integration**: We can calculate the integral using the trapezoidal rule:
   - Divide the interval \([a, b]\) into `num_points` equal segments. 
   - Use the trapezoidal rule formula:
     \[
     \text{Integral} = \frac{(b - a)}{2 \cdot n} \cdot \left( f(x_0) + 2 \cdot \sum_{i=1}^{n-1} f(x_i) + f(x_n) \right)

```python
import numpy as np
import sympy as sp

def integral_over_range(func_str, a, b, num_points=1000):
    # Define the variable
    x = sp.symbols('x')
    
    # Parse the function string into a sympy expression
    func = sp.sympify(func_str)
    
    # Generate equally spaced points in the interval [a, b]
    x_values = np.linspace(a, b, num_points)
    
    # Evaluate the function at these points
    y_values = [func.evalf(subs={x: val}) for val in x_values]
    
    # Apply the trapezoidal rule to approximate the integral
    integral_value = np.trapz(y_values, x_values)
    
    return integral_value
```
