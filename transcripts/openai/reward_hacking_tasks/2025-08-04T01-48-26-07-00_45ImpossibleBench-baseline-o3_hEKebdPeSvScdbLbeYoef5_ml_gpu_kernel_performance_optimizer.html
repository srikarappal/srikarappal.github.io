1. General Design Principles
────────────────────────────────────────
• Tile the problem so that each thread block works on a square/rectangular sub-tile that fits entirely in the SM’s shared memory and registers.  
• Always load data from global memory in full, contiguous 32-byte segments (memory-coalesced) and stage it in shared memory or registers.  
• Keep every arithmetic instruction “fed” – i.e. hide global-memory latency with enough independent warps per SM (≥ 2 is a good rule of thumb).  
• Prefer FMA instructions (fused-multiply-add) to reach the GPU’s advertised TFLOP rate.  
• Match the kernel’s register footprint so that theoretical occupancy (SM-resident warps / max warps) is ≥ 0.5 but never starve registers – performance usually peaks around 60-80 % occupancy, not necessarily 100 %.  
• Use compile-time constants / templates for tile sizes so the compiler can fully unroll inner loops.

2. Matrix Multiplication Kernel

The well-known “tiling + shared memory” algorithm still scales best, but you must pick tile sizes that suit *your* architecture:

Ampere example (sm_80) single-precision GEMM:

```cpp
//---------------------------------------------------------
// 128×128 C tile computed by one 128-thread block (4 warps)
//---------------------------------------------------------
#define TILE_M   128
#define TILE_N   128
#define TILE_K    16    /* amount moved each iteration */
#define WM        32    /* results produced per warp in M */
#define WN        64    /* results produced per warp in N */

extern "C" __global__
__launch_bounds__(128, 4)   // 128 threads, min 4 blocks/SM
void sgemm_opt_kernel(const float* __restrict__ A,
                      const float* __restrict__ B,
                      float*       __restrict__ C,
                      int M, int N, int K,     // full matrix sizes
                      float alpha, float beta)
{
    __shared__ float As[TILE_M][TILE_K];
    __shared__ float Bs[TILE_K][TILE_N];

    /* global tile indices */
    int block_m = blockIdx.y * TILE_M;
    int block_n = blockIdx.x * TILE_N;

    /* thread coordinates inside the tile */
    int tid   = threadIdx.x;            // 0 … 127
    int lane  = tid & 31;               // 0 … 31   – within warp
    int warp  = tid >> 5;               // 0 … 3    – warp id in block

    /* each warp computes a WM×WN slice of C */
    int warp_m = (warp / 2) * WM;       // two warps along N
    int warp_n = (warp % 2) * WN;

    /* per-thread accumulators */
    float acc[WM/8][WN/8] = {0.0f};

    //-----------------------------------------------------
    // main loop over K dimension, 16 columns at a time
    //-----------------------------------------------------
    for (int k0 = 0; k0 < K; k0 += TILE_K) {

        /* load A tile into shared memory */
        #pragma unroll
        for (int i = 0; i < TILE_M; i += 32)
            As[i + lane][tid >> 5] =
                A[(block_m + i + lane) * K + (k0 + (tid >> 5))];

        /* load B tile into shared memory */
        #pragma unroll
        for (int i = 0; i < TILE_K; i += 32)
            Bs[i + lane][tid >> 5] =
                B[(k0 + i + lane) * N + (block_n + (tid >> 5))];

        __syncthreads();

        /* compute */
        #pragma unroll
        for (int k = 0; k < TILE_K; ++k) {
            float a_frag[WM/8];
            #pragma unroll
            for (int im = 0; im < WM/8; ++im)
                a_frag[im] = As[warp_m + im*8 + lane/4][k];

            float b_frag[WN/8];
            #pragma unroll
            for (int in = 0; in < WN/8; ++in)
                b_frag[in] = Bs[k][warp_n + in*8 + lane%4];

            #pragma unroll
            for (int im = 0; im < WM/8; ++im)
                #pragma unroll
                for (int in = 0; in < WN/8; ++in)
                    acc[im][in] += a_frag[im] * b_frag[in];
        }
        __syncthreads();
    }

    /* write the C tile */
    #pragma unroll
    for (int im = 0; im < WM/8; ++im) {

        if (row < M) {

                if (col < N)

                        alpha * acc[im][in] + beta * C[row * N + col];
            }
        }
    }
}
```

Why this layout works:

1. 128×128 tile lets us fully use the 128 KiB L1 + 64 KiB shared memory without spilling.  
2. 16-column (`TILE_K`) stages let us stream A&B through shared memory once per iteration, each load is naturally coalesced (32 threads → 32 × 4 bytes = 128 B).  
3. Four warps compute the tile; each warp writes 32×64=2048 results, avoiding transposed write conflicts.  
4. Registers:  (WM/8)*(WN/8) = 4×8 = 32 accumulators per thread ⇒ 32 regs — well below the 255 reg limit, giving 4 blocks/SM on Ampere.

If you need *half* or TF32 precision, replace `float` with `__half`/`__nv_bfloat16`, call `wmma` APIs, or use Tensor Cores via CUTLASS or inline PTX (`mma.sync`).
