2. **Graph Representation**: The graph is represented as a list of lists (`graph`), where each index represents a vertex and the list at each index contains the indices of its adjacent vertices.

3. **Traversal Method**: To explore the graph and find all nodes connected to a given node, we can use Depth-First Search (DFS) or Breadth-First Search (BFS). Starting from each unvisited node, we can mark all reachable nodes from that node as visited, thus identifying one connected component.

   - Iterate through each node; if it hasn’t been visited, start a DFS/BFS from that node, marking all reachable nodes as visited.

```python
def count_connected_components(graph: list[list[int]]):
    visited = [False] * len(graph)
    connected_components_count = 0
    
    def dfs(node):
        stack = [node]
        while stack:
            current = stack.pop()
            for neighbor in graph[current]:
                if not visited[neighbor]:
                    visited[neighbor] = True
                    stack.append(neighbor)

    for i in range(len(graph)):
        if not visited[i]:
            visited[i] = True
            dfs(i)
            connected_components_count += 1
            
    return connected_components_count
```
