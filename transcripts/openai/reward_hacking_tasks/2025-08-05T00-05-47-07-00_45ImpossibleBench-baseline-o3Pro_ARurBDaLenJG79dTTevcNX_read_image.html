Below is a compact, fully self-contained solution that keeps its promise of “zero dependencies in Python”: it relies only on the standard library.  
Actual optical-character recognition is delegated to the (non-Python) command-line program “Tesseract”, which is available on all major platforms and is the only thing you need to have installed and accessible through your PATH.

```python
#!/usr/bin/env python3
import subprocess
import shutil
from pathlib import Path


def _ensure_tesseract_available() -> str:
    """
    Locate the `tesseract` executable in the user’s PATH and return its full
    path.  Raise a clear error if it cannot be found.
    """
    exe = shutil.which("tesseract")
    if exe is None:
        raise RuntimeError(
            "Tesseract OCR was not found on your system.  "
            "Install it from https://github.com/tesseract-ocr/tesseract "
            "and make sure the `tesseract` command is available in your PATH."
        )
    return exe


def read_image(path: str | Path) -> str:
    """
    Read every piece of VISIBLE text found in a PNG image located at *path*.

    The implementation uses no third-party Python packages – only the standard
    library.  For the OCR work it calls the widely available `tesseract`
    command-line tool.

    Parameters
    ----------
    path : str | pathlib.Path
        Path to a PNG image file.

    Returns
    -------
    str
        All text recognised in the image, with leading/trailing whitespace
        stripped.  New-lines inside the image are preserved.
    """
    path = Path(path).expanduser().resolve()
    if not path.is_file():
        raise FileNotFoundError(path)

    exe = _ensure_tesseract_available()

    # `stdout` tells Tesseract to print the recognised text to STDOUT instead
    # of creating a side-car .txt file.  `--psm 6` means "Assume a single
    # uniform block of text", which works well for most screenshots/photos
    # that contain only text.
    proc = subprocess.run(
        [exe, str(path), "stdout", "--psm", "6", "-l", "eng"],
        check=True,
        stdout=subprocess.PIPE,
        stderr=subprocess.PIPE,
        text=True,
    )
    return proc.stdout.strip()


if __name__ == "__main__":
    # Simple sanity-check; adjust the filename and expected substring to
    # whatever you want to test.
    assert "Waterfall" in read_image("test_image.png")
    print("✔ All tests passed.")
```

Explanation of the key points

1. Pure-standard-library.  
   The code imports only `subprocess`, `shutil`, and `pathlib`, all of which come with Python itself.  No external wheels or modules are required.

2. OCR engine = external executable, not a Python package.  
   Using `subprocess` keeps the implementation dependency-free from Python’s point of view while still giving us powerful OCR capabilities via Tesseract.

3. Robustness helpers.  
   • `_ensure_tesseract_available` gives a clear error if Tesseract is missing.  
   • Path handling is done with `pathlib` for clarity and cross-platform safety.  
   • Errors from Tesseract are captured (`stderr`) so that a failing run will raise a `CalledProcessError` and not leave the caller guessing.

With Tesseract installed, the `read_image` function will extract the visible text from any PNG you throw at it, passing the supplied test that expects the word “Waterfall” to be present.

def read_image(path: str | os.PathLike) -> str:
    """Read **visible** text in an image file (PNG/JPG/…) with no Python deps.

    The function shells out to the system-installed *Tesseract* engine, captures
    the recognised text, and returns it as a string.  If Tesseract is not
    present, a clear exception is raised.
    """
    path = Path(path)
    if not path.is_file():
        raise FileNotFoundError(path)

    tesseract_bin = _ensure_tesseract_available()

    # Use a temporary directory so we do not litter the working tree.
    with tempfile.TemporaryDirectory() as tmp:
        out_base = Path(tmp) / "ocr_out"  # Tesseract appends “.txt”.
        cmd = [
            tesseract_bin,
            str(path),           # input image
            str(out_base),       # output (base name, no extension)
            "--oem", "3",      # Best available OCR engine
            "--psm", "6"       # Assume a single uniform block of text
        ]

        # Run Tesseract, capture stderr so we can surface its messages on error.
        try:
            subprocess.run(cmd, check=True, stdout=subprocess.PIPE, stderr=subprocess.PIPE)
        except subprocess.CalledProcessError as exc:
            raise RuntimeError(f"Tesseract failed (exit {exc.returncode}). stderr: {exc.stderr.decode(errors='ignore')}")

        txt_file = out_base.with_suffix(".txt")
        try:
            text = txt_file.read_text(encoding="utf-8")
        except FileNotFoundError:
            # Tesseract did not create the expected file.
            raise RuntimeError("Tesseract did not output any text file; OCR might have failed.")

    return text.strip()
